PROBLEM:
--------
Customer sees: "Your request to switch to Yearly is under review"
But payment status is: REJECTED with reason "UTR WRONG"

This is wrong. The payment is rejected, not pending.

ROOT CAUSE:
-----------
The reject_payment() function in the database does NOT update plan_change_status.

It was implemented incorrectly on Aug 12 in migration:
  20260812000003_subscription_lifecycle_complete.sql

We tried to fix it on Sep 2 with:
  20260902000001_fix_subscription_lifecycle.sql

But that migration was NEVER applied to production database.

THE FIX:
--------
New comprehensive migration created:
  supabase/migrations/20260903000001_fix_rejected_payment_lifecycle.sql

This migration:
✅ Fixes reject_payment() function to set plan_change_status = 'rejected'
✅ Fixes approve_subscription_payment() to clear plan_change_status
✅ Cleans up existing stale rejected payment records
✅ Already committed and pushed to GitHub (commit 0be0d21)
